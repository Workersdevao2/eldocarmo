# Eldo Carmo Portal — eldocarmo.com

Elegant split-image gateway to the two brand sites.

## Deploy
Push this folder to its own GitHub repo → connect to Cloudflare Pages (Framework: None, Output: `/`).

## Structure
- `index.html` — single-page portal
- `css/style.css` — full styles + responsive
- `js/main.js` — parallax + keyboard access
- `assets/images/` — logos + split-hero.png
